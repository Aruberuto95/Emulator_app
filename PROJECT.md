# Project: FFI Bridge Emulator

## Architecture
This project implements a high-performance multi-console emulator with a Rust backend (core) and a C++ frontend (SDL2) communicating via a zero-copy FFI boundary generated by `cxx`.

```
                  +--------------------------------+
                  |          C++ Frontend          |
                  |     (SDL2 Event Loop & I/O)    |
                  +---------------+----------------+
                                  |
                   FFI Bridge     | (Zero-copy Buffers & Control)
                  (cxx::bridge)   |
                                  v
                  +---------------+----------------+
                  |           Rust Core            |
                  |     (State, Pixel/PCM Gen)     |
                  +--------------------------------+
```

### Key Modules:
1. **Root Build Configuration**: A top-level CMake configuration linking Cargo-based Rust build and C++ frontend build.
2. **Rust Core (`emulator_core`)**: The Rust crate implementing emulator logic, maintaining a static or pre-allocated pixel frame buffer (e.g., 256x240 RGB or similar) and PCM audio buffer (e.g., 44100Hz stereo), preventing heap allocations during active execution steps.
3. **C++ Frontend**: Initializes SDL2 for video rendering, audio playback, and controller inputs, running an event loop that polls inputs, passes them to Rust, ticks the emulator, and draws/plays the returned buffer contents.

## Interface Contracts
The FFI boundary is defined using `cxx::bridge`.

### Rust Types Exposed to C++
- `struct ButtonState` containing digital button inputs (e.g., UP, DOWN, LEFT, RIGHT, A, B, START, SELECT).
- Opaque type `Emulator` representing the emulator instance.

### FFI Functions (in C++ namespace `ffi`)
- `std::unique_ptr<Emulator> create_emulator()`: Initializes the Rust emulator core.
- `void play(Emulator& emu)`: Starts/resumes emulator execution.
- `void pause(Emulator& emu)`: Pauses emulator execution.
- `void reset(Emulator& emu)`: Resets emulator state.
- `void tick(Emulator& emu)`: Executes a single frame/tick.
- `void inject_input(Emulator& emu, ButtonState buttons)`: Passes controller inputs for the current frame.
- `rust::Slice<const uint8_t> get_video_buffer(const Emulator& emu)`: Returns a zero-copy slice to the pre-allocated frame buffer.
- `rust::Slice<const int16_t> get_audio_buffer(const Emulator& emu)`: Returns a zero-copy slice to the pre-allocated audio buffer.

## Code Layout
- `CMakeLists.txt` - Root CMake configuration.
- `Cargo.toml` - Root Cargo configuration.
- `core/` - Rust crate folder.
  - `Cargo.toml`
  - `src/lib.rs` - Library entry point and `cxx::bridge`.
  - `src/emulator.rs` - Emulator struct and logic (no-alloc execution loop).
- `frontend/` - C++ application folder.
  - `CMakeLists.txt`
  - `src/main.cpp` - SDL2 bootstrap, event loop, and FFI interaction.
- `tests/` - E2E tests folder.
