# Test Readiness Manifest: FFI Bridge Emulator

This manifest tracks the verification status and provides instructions for compiling and executing the End-to-End (E2E) test suite of the FFI Bridge Emulator.

---

## 1. System Requirements & Setup
- **Operating System**: macOS (13.0 or later recommended)
- **Compiler**: Clang (supporting C++17 or later)
- **Rust Toolchain**: `rustc` / `cargo` (1.70.0 or later recommended)
- **CMake**: version 3.20 or later
- **Dependencies**: SDL2 (install via `brew install sdl2`)
- **Python**: Python 3.10+ (with `pytest`)

---

## 2. Compilation and Build Commands
Verify that the hybrid workspace compiles cleanly:
```bash
# Configure the build with CMake
cmake -B build -S . -DCMAKE_BUILD_TYPE=Debug

# Compile all targets (C++ frontend, Rust core, and Test Suite)
cmake --build build
```
*Acceptance Criteria*: Compilation completes without warnings, and C++ header files generated by `cxx` are correctly included.

## 4. Executing the Test Suite

### 4.1. Automated Python Pytest E2E Execution
Run the full E2E test suite using python's `pytest` framework:
```bash
pytest tests/
```

### 4.2. Automated CTest Execution
Run all unit and E2E tests via CMake's test runner:
```bash
ctest --test-dir build --output-on-failure
```

### 4.3. Running Headless C++ Frontend Test
To test the real C++ SDL2 frontend executable in a headless display environment:
```bash
# Force SDL2 to use dummy video and audio drivers
export SDL_VIDEODRIVER=dummy
export SDL_AUDIODRIVER=dummy

# Execute frontend with automatic exit flag (if implemented) or verification script
./build/frontend/clothing_app_frontend --test-duration 100
```

## 5. Security & Verification Assertions
1. **Safety**: No `unsafe` block usage for standard FFI boundary data transfers.
2. **Buffer Alignment**: Video and audio memory pointer equality assertions check that pointers from `get_video_buffer` and `get_audio_buffer` are stable across ticks.
3. **Leak Detection**: Run with AddressSanitizer:
   ```bash
   cmake -B build -S . -DUSE_ASAN=ON && cmake --build build
   ctest --test-dir build --output-on-failure
   ```
